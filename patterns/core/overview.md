# Core Haskell patterns

Use these documents when starting a package or making a convention that will
affect most modules.

- [Haskell Core Standards](standards.md) is the baseline and takes precedence.
- [Record Patterns](record-patterns.md) defines record shape and label usage.
- [Custom Prelude Pattern](custom-prelude.md) keeps common imports controlled.
- [Multiline String Literals](multiline-strings.md) covers indentation-aware
  embedded text on GHC 9.12 and newer.
